Paste Guard

Take the personal details out of a case note before you paste it into an AI assistant. Put them back in the answer.

Runs in this tab. Nothing is sent or saved.

Read the redacted text before you paste it

This tool finds phone numbers, emails, IBANs, ID and case numbers reliably. Names are harder. It recognises a name after a title or a cue such as Mr, Mme, السيد, son of, or when it is in a built-in list of common names. A name with no cue that is not in the list can slip through. Check every name yourself, and select anything it missed.

    How the privacy claim is enforced

    • The page has a Content-Security-Policy with connect-src 'none', so the browser refuses any network request from it.
    • The mapping from placeholders to real values is a plain object in this tab's memory. It is never written to browser storage or sent anywhere, and it is gone when you close or reload the page.
    • A test fails the build if the code mentions fetch, XMLHttpRequest, WebSocket, sendBeacon, local storage or cookies.
    • There is no name-recognition model. Names are found by cues and a bundled list, so some will be missed. That is why step 2 asks you to read the result.

    Paste Guard is a portfolio project with synthetic sample data. It reduces risk; it does not make a note safe to share.
